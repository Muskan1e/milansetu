# MilanSetu Matrimony Website (fixed version)

Pages: index, browse-profile, profile-details, membership, success-stories, contact-us.
Open index.html with Live Server (internet needed only for Google Fonts).

## Quick controls (css/style.css, top of file)
- --container: 1920px  -> max page width
- --gutter: 15px       -> left/right space
- html font-size       -> all text/spacing scale from this one rule

## Images
All photos are local in assets/images/. To use your original high-resolution
photos, replace the files with the SAME file names (bride-01.jpg, gallery-1.jpg,
story-1.jpg, belief-front.jpg, hero-couple.jpg ...).
Member data (names, filters) is in js/data.js.
